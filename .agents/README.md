# Canonical agent assets

This directory is provider-neutral:

- `organization.json` defines roles, workspaces, budgets and decision owners.
- `roles/` defines each recurring agent role exactly once.
- `skills/` contains portable Agent Skills loaded only when their descriptions
  match the task.

`.codex/agents`, `.claude/agents` and `.gemini/agents` are thin discovery and
permission adapters generated by `npm run adapters:generate`. They must reference
canonical roles, not redefine policy; `npm run adapters:check` rejects drift.

Do not add a role for every job title. Add one only when it has a distinct
recurring task, authority boundary, tool profile and test. Do not add a skill
until its workflow, input, output and validation are stable. Provider-native
skills are optional accelerators and are never copied into this directory.
