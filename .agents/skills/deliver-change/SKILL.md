# Deliver a bounded change

1. Read the work item when required, nearest instructions and touched files only.
2. Confirm acceptance, allowed paths, budgets, exclusive resources and stops.
3. Act within guardrails; record reversible assumptions instead of asking.
4. Coordinate or escalate only when another owner or material decision is needed.
5. Preserve unrelated work and implement the smallest coherent solution.
6. Run relevant checks and retry the same cause at most twice.
7. Checkpoint before provider/session transfer or noisy compaction.
8. Return a run report; never merge, deploy or accept risk.
