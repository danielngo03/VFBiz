# Triage a change

1. Preserve the request and state one outcome plus explicit non-goals.
2. Inspect target paths, nearest instructions and existing tests before asking.
3. Identify the owning workspace, crossed boundaries and controlled signals.
4. Select the smallest valid mode from `docs/operating-model/delivery-and-authority.md`.
5. Apply its agent, document, skill, review and claim budgets.
6. Use a reversible repository convention for non-material ambiguity and record it.
7. If scope, risk or irreversible action needs human authority, return a decision
   packet with evidence, at most three options and one recommendation.

Return a request envelope and exact next action. Do not plan unrelated work.
