# Quy tắc open-source, brand và intellectual property

Proposal này chặn dùng asset/dependency bên ngoài cho tới khi human owner cần
thiết phê duyệt.

- Không copy code website, logo, ảnh, model 3D, font, text, dataset hoặc giá bên
  thứ ba chỉ vì chúng truy cập công khai được.
- Trước khi import asset/dataset, ghi source URL, owner, license/permission,
  allowed use, territory, expiry và takedown procedure.
- Ưu tiên dependency có commercial-use term rõ và được duy trì. Copyleft,
  network-copyleft, source-available, non-commercial, model-weight và data
  license cần written Legal review.
- Pin dependency, giữ notice, tạo SBOM và scan advisory khi có runtime code.
- Community agent skill là executable supply-chain input; phải review provenance,
  instruction, script, network và secret access trước khi cài.
- Brand similarity chỉ là design reference, không phải quyền sao chép protected
  identity. Production content cần Brand Owner thật của tổ chức.
